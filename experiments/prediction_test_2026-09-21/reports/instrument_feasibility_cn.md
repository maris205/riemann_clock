# Fe II 宇宙时间预言实验：现有仪器可执行性

核查基准日：2026-09-21。结论：**现有设备可以开展这个预先规定、留出检验样本的实验；但光谱覆盖不等于精度已达标，更不保证发现。** 本文只核查设备、标定与对照设计，不增加科学观测，不把当前数据中的差异当成未来预言的固定幅度。

## 1. 主观测设置与必须修正的波段假设

ESPRESSO 的科学波段为 380–788 nm。优先使用单 UT 的 HR 模式，中位分辨率约 140,000；UHR 约 190,000，但通光效率较低，应由具体目标的曝光计算决定，不能仅追求最高分辨率。[ESO 模式表](https://www.eso.org/sci/facilities/paranal/instruments/espresso/overview.html)

**当前 LFC 的蓝端约为 450 nm，不能把 380–788 nm 的科学波段全称为光梳覆盖。** P117 手册 §3.4.1 说明，更换 PCF 后蓝端收缩；2025-11-21 恢复科学使用，2026 年 4 月又更新了扰模单元。手册展示的 5.8 m/s 是特定标定试验、特定迹线及自建处理的局部指标，不是每个类星体的谱线误差保证。[P117 手册](https://www.eso.org/sci/facilities/paranal/instruments/espresso/ESPRESSO_User_Manual_P117.pdf) 官网 2026-02-11 通知确认已恢复 LFC 科学申请。[ESO 新闻](https://www.eso.org/sci/facilities/paranal/instruments/espresso/news.html)

使用同一对 Fe II 2374/2382 Å，按本地原子表中的真空波长计算下列**几何位置**。这些红移是设计中心，不是已经确认合格的目标。

| 吸收红移 | 2374 / 2382 观测波长（nm） | 设计地位与边界 |
|---|---|---|
| 0.7 | 403.658 / 405.070 | 在科学波段内，但低于当前 LFC 蓝端；不作为主光梳样本 |
| 1.0 | 474.892 / 476.553 | 主设计低红移中心；逐条核验实际光梳与级次质量 |
| 1.2 | 522.381 / 524.208 | 可选中间覆盖；邻近蓝／红探测器分界，需逐文件确认 |
| 1.5 | 593.615 / 595.691 | 主设计中间中心 |
| 2.0 | 712.338 / 714.829 | 主设计高红移中心；水汽污染筛查尤其关键 |

全科学波段的名义共同覆盖为约 `0.6004 ≤ z ≤ 2.3071`；以 450 nm 蓝端计算，主线对的名义光梳低限约为 `z ≥ 0.8952`，应留余量。上述界限未计入光梳逐级次质量、大气、天光、像素缺陷或吸收线是否真实存在。

主统计量始终使用这同一对谱线；2260/2344 Å 可作为跨三组共用的气体结构辅助线。尤其 2260 在 z=1 时约为 452.156 nm，接近当前光梳蓝端，不能默认标定质量足够。2586/2600 Å 仅在预先规定的质量条件下作辅助；不能因某组缺线而临时改变主统计量。辅助线不一定可检测，强线饱和也不能靠“同离子”自动消除。

## 2. 可执行的标定与观测安排

P117 说明 LFC/ThAr 在白天使用，不提供夜间紧接科学曝光的标定；B 光纤在天空与 FP 参考间选择。暗目标通常优先天空模式，以避免参考光污染；不能安排同一根 B 光纤同时观测天空和 FP。手册还指出 700–800 nm 水汽线较多，高红移组应先用大气模型和目标可见性选择红移窗口，再冻结样本，而不是看见科学位移后换窗口。[P117 手册，§5.2、§7.1、§7.2.5、§8](https://www.eso.org/sci/facilities/paranal/instruments/espresso/ESPRESSO_User_Manual_P117.pdf)

建议采用以下设计规则；它们是本项目提出的实验方案，不是 ESO 已经批准或执行的项目：

1. 三个红移组都采用同一主仪器、模式、分析定义和匹配的标定链。各组穿插不同观测夜，避免红移与仪器时期完全重合。
2. 每个目标至少安排两个可比较的观测批次；按坐标和季节争取明显不同的 BERV，使谱线在探测器及地球大气坐标中的位置改变。实际速度间隔由可见性计算决定，不承诺所有目标都能实现。
3. 保留原生曝光、级次和两条迹线。仅当同一谱线确实落在两个有效级次中时，作独立级次对照；不把同一像素重复算入联合似然。
4. 从匹配的独立标定曝光约束每级次／迹线的波长解及线扩散函数，并记录版本、输入和质量指标。用科学谱反推的仪器核可以作为敏感性分析，不能再称为独立验证。
5. 对每个红移组都选取跨仪器复测子样本，不能让低红移只由 ESPRESSO 测、高红移只由 UVES 测。仪器差在同一吸收系统内估计，宇宙时间差在不同吸收系统之间估计。

UVES 的蓝／红臂分别覆盖 300–500 与 420–1100 nm；窄缝最高分辨率约 80,000／110,000，足以作独立光路的模型及标定对照。实际设置、探测器缺口和信噪比仍需逐目标 ETC 检查；UVES 不因“独立”就自动成为绝对真值。[ESO UVES 参数](https://www.eso.org/sci/facilities/paranal/instruments/uves/inst.html)

## 3. 时间、环境和仪器怎样分别检验

同一吸收系统换季节、BERV、迹线、级次或仪器，主要检验观测与模型的稳定性；这些短期复测并未提供相隔几十亿年的宇宙年龄。主时间比较来自不同吸收红移的系统。

每个年龄组内部至少需要多个独立视线，并尽量匹配吸收深度、速度宽度、饱和程度、金属线强度及可测环境指标。还应保留近红移、不同视线的控制组：如果它们的差异与跨红移组一样大，就不能把总散布直接归为时间演化。相同红移主要固定观测波长，不能单独证明仪器无偏；跨仪器及独立标定仍必要。环境不可完全观测，残余混杂必须进入模型和结论。

对“真实宇宙谱线差异”的预言应当要求：在事先未用于确定幅度的目标上，给定时间函数预测的相对频率差得到复现；而同一系统的结果对 BERV、级次、迹线和独立仪器保持相容。若差异追随探测器位置或标定方案变化，优先归入系统效应。若跨仪器稳定但同红移散布主导，则应先研究环境或吸收结构，而非直接宣布宇宙时间规律。

## 4. 精度与进度的诚实边界

`c/R` 是仪器分辨宽度，不是线心不确定度。当前项目中两个旧档案目标的条件性局部误差约 180 与 399 m/s，也不能当作高质量新数据的不可突破下限。未来功效计算可以列出更好的精度情景，但必须标注是假设，并通过目标级注入恢复验证；统计误差、标定共模和气体结构不确定度不能简单等同。

先导阶段应先选真实目标、用 ETC 计算两条主线附近的信噪比，再在原生采样、真实 LSF、天空和气体结构下开展盲注入；达到协议预定的总误差和覆盖率后，才把样本数换算成望远镜小时数。未完成这一步，不承诺每目标若干小时可达到若干 m/s，也不承诺十年内必有发现。现有仪器足以启动，不需要把 ANDES 的未来交付作为实验成立的前提。
